\chapter*{Resumen}

El presente \underline{trabajo (o informe)} aborda el problema de la detección de anomalías en conjuntos de datos de salud, enfocándose en el diagnóstico temprano y la prevención de enfermedades como la diabetes. Se emplea la arquitectura de Autocodificadores (\textit{Autoencoders}), una clase de red neuronal no supervisada, para aprender una representación compacta y eficiente de los patrones de datos normales. El modelo se entrena utilizando el conjunto de datos \textbf{Diabetes Health Indicators Dataset}, donde se considera anómalo cualquier patrón que se desvía significativamente de la reconstrucción esperada. \chapter{Introducción}

\textbf{Describir el problema que se desea resolver}\\

La detección de anomalías es un campo fundamental dentro del análisis de datos, cuyo objetivo principal es la identificación de patrones que no se ajustan a un comportamiento \underline{esperado (o normal)}. En el contexto de los datos de salud, una anomalía puede representar un error de medición, o una indicación temprana de una condición médica patológica, como la diabetes. Este trabajo se centra en desarrollar un sistema robusto para la detección automática de tales desviaciones. Se busca resolver la limitación de los métodos estadísticos tradicionales, los cuales a menudo no logran capturar las complejas interrelaciones no lineales presentes en conjuntos de datos de alta dimensionalidad. El problema específico que se aborda es cómo entrenar un modelo para que aprenda exclusivamente el perfil de pacientes \underline{'normales' o 'típicos' (o sanos)} a partir de un conjunto de datos con \underline{distintos balance de clases (quiero representar lo de varios porcentajes)}, y cómo utilizar su error de reconstrucción para señalar con precisión qué registros se consideran anómalos.

\section{Motivación}

\textbf{Explicar porqué estudiamos este problema, para qué sirve, cuál es el impacto y en qué áreas.}\\

El diagnóstico temprano de enfermedades como la diabetes es una tarea prioritaria en la medicina moderna.  
Muchas veces, los datos de salud contienen información sutil que puede pasar desapercibida mediante métodos tradicionales de análisis.  
El uso de redes neuronales, y en particular de autocodificadores, permite automatizar este proceso y detectar posibles irregularidades en grandes volúmenes de datos de manera eficiente.

Este tipo de sistemas podría integrarse en plataformas de monitoreo de salud, ayudando a profesionales médicos a detectar patrones atípicos o pacientes en riesgo antes de que aparezcan síntomas clínicos evidentes.

\subsubsection{Estandarización de atributos no binarios}

El conjunto de datos contiene atributos con diferentes rangos de valores; por ejemplo, el \textbf{BMI} es continuo, mientras que \textbf{Age}, \textbf{Education} e \textbf{Income} son escalas ordinales. Esta diferencia de escalas puede afectar el rendimiento de los algoritmos de optimización (como el Descenso de Gradiente) en el autocodificador, ya que las características con rangos más grandes dominarían la función de pérdida.

Para mitigar esto, apliqué una estandarizacióna a todos los atributos no binarios. La estandarización transforma las variables para que tengan una media ($\mu$) de cero y una desviación estándar ($\sigma$) de uno, asegurando que todas las entradas al modelo tienen una escala comparable. Se realiza de la siguiente manera:

\[
z = \frac{x - \mu}{\sigma}
\]
donde $x$ es el valor original del atributo, $\mu$ es su media y $\sigma$ es su desviación estándar.

\subsubsection{Cálculo de la matriz de correlación}

Calculo la matriz de correlación ($\rho$), la cual mide el grado de asociación lineal entre cada par de atributos del conjunto de datos. Se calcula de la siguiente manera:

\[
\rho(X, Y) = \frac{Cov(X, Y)}{s_x s_y}
\]

Donde $Cov(X, Y)$ representa la covarianza entre $X$ e $Y$, y $s_x$, $s_y$ son sus desviaciones estándar. La covarianza se define como:

\[
Cov(X, Y) = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})
\]

\chapter{Descripción de los Métodos Utilizados}

%prueba \cite{santos2025}

El método empleado en este proyecto es el \textbf{Autocodificador (\textit{Autoencoder})}. Un autocodificador es un tipo de red neuronal artificial diseñada para aprender una representación codificada de un conjunto de datos de manera no supervisada. La arquitectura se compone de dos partes principales: el \textbf{Codificador (\textit{Encoder})} y el \textbf{Decodificador (\textit{Decoder})}.

\section{Arquitectura y principio de funcionamiento}

Un autocodificador es un tipo de perceptrón multicapa, con la particularidad de ser simétrico respecto a su \textbf{capa latente}. La dimensión de la entrada ($d$) coincide con la dimensión de la salida, y el aprendizaje es no supervisado, ya que la salida esperada ($Y$) es la propia entrada ($X$).

\subsection{Componentes clave}

El codificador comprime la entrada en una representación en la capa latente. La capa latente es la capa oculta central, usualmente con una dimensión $k$ que es menor que la dimensión de la entrada ($k < d$). Esta capa contiene la representación comprimida de los datos. El decodificador, la segunda mitad de la red, reconstruye la salida $Y$ a partir de la representación latente.

\subsection{Función de activación (GeLU)}

Se emplea la función \textbf{GeLU (\textit{Gaussian Error Linear Unit})} para introducir la no linealidad necesaria en las capas ocultas. Esta función es elegida sobre otras alternativas como la ReLU (Rectified Linear Unit), buscando mayor estabilidad y mejor rendimiento en modelos profundos.

\section{Uso para la detección de anomalías}

La aplicación del autocodificador para este caso es la \textbf{detección de datos atípicos}, explotando la diferencia en la capacidad de la red para reconstruir datos conocidos.

\subsection{Criterio de detección}

El modelo se entrena inicialmente con la clase que representa el comportamiento \textbf{normal}, es decir, los pacientes sin diabetes. Al presentar un dato $t$ que sigue la misma distribución, se espera que el error de reconstrucción sea pequeño.

Sin embargo, si se presenta un dato atípico ($t^*$), el modelo no es capaz de reconstruirlo fielmente, lo que resulta en un error de reconstrucción significativamente alto. Un dato $t^*$ se considera anómalo si su error de reconstrucción excede un umbral predefinido ($\epsilon$).

\[
||t^{*}-t^{\prime*}|| \gg \epsilon
\]
donde $t^{\prime*}$ es el dato reconstruido por la red.

\section{Determinación del umbral y métricas de evaluación}

La Detección de Anomalías utilizando un Autocodificador es una tarea de clasificación binaria, donde se compara el error de reconstrucción de un registro con un umbral predefinido $\epsilon$.

\subsection{Clasificación de resultados}

Para evaluar el rendimiento del modelo, se definen los siguientes criterios de clasificación en función del error de reconstrucción ($||t' - t||$) y el umbral $\epsilon$:

\begin{itemize}
	\item \textbf{Verdaderos Positivos (TP)}: Casos anómalos (Con diabetes) con un error de reconstrucción $||t' - t||> \epsilon$.
	\item \textbf{Falsos Negativos (FN)}: Casos anómalos (Con diabetes) con un error de reconstrucción $||t' - t|| \le \epsilon$.
	\item \textbf{Verdaderos Negativos (TN)}: Casos normales (Sin diabetes) con un error de reconstrucción $||t' - t|| \le \epsilon$.
	\item \textbf{Falsos Positivos (FP)}: Casos normales (Sin diabetes) con un error de reconstrucción $||t' - t|| > \epsilon$.
\end{itemize}
